# sba3
Maison Soleil | Booking Confirmation
A responsive hotel booking confirmation page built to recreate a polished interface while transitioning from Bootstrap to Tailwind CSS.
Implementation & Technologies
HTML5 and CSS3
Tailwind CSS v4
Bootstrap Icons and Google Fonts
Node.js and npm
Git and GitHub
Migrated layout, spacing, alignment, and responsive utilities from Bootstrap to Tailwind CSS v4 using its CLI. Retained custom CSS where necessary to preserve visual styling and complex responsive behavior.
Reflection
This project helped me compare Bootstrap and Tailwind CSS through hands-on implementation. I found Bootstrap’s structure less intuitive and sometimes confusing, particularly when trying to understand how its predefined classes interact with custom CSS. Tailwind felt more logical because its utility classes describe specific styling decisions directly in the HTML, making layout and spacing easier to understand and adjust. The migration also taught me to work incrementally, test changes visually, and recognize when existing custom CSS should remain untouched to avoid breaking responsive behavior. In future projects, I would continue exploring Tailwind’s responsive utilities and look for opportunities to reduce unnecessary custom CSS while maintaining a clear, maintainable codebase.
